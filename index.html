FAQ

Questions, answered

Do I need an account?

No. Open the site, create an agent and start chatting. Everything is stored in your browser.

Do I need an API key?

No. On a computer with WebGPU, Agora AI runs locally, and web search needs no key. A key in Settings is optional if you want to connect online.

Does it work on my phone?

Many phones don't have WebGPU, so the local AI may not run there. Search links still come back, and a key in Settings lets Agora AI answer online.

Where does web search look?

Wikipedia, DuckDuckGo quick answers, and public pages read through the Jina reader. A reply lists a source only when it actually used it.

Is Agora finished?

Agora is in beta, so new features are still landing. Check the changelog on GitHub to see what's new.
