FAQ

Questions, answered.

Do I need an account?

No. Open Agora, create an agent and start chatting. Everything is stored in your browser.

Do I need an API key?

No. On a computer with WebGPU, Agora 1.0 runs locally, and web search needs no key. A key in Settings is optional.

Does it work on my phone?

Many phones don't have WebGPU, so the local AI may not run there. Search links still come back, and a key in Settings lets Agora 1.0 answer online.

Where does web search look?

Wikipedia, DuckDuckGo quick answers, and public pages read through the Jina reader. A reply lists a source only when it used it.

Is Agora finished?

Agora is in beta, so new features are still on the way.
